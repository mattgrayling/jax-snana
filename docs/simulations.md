# Simulations

jax-snana can simulate light curves and spectra for a survey, using a SIMLIB
to specify the observing times and conditions. The simulated supernova
population, observing conditions and selection effects can be configured
to suit the survey you want to model.

If you are using jax-snana for the first time, the {doc}`getting_started`
page provides an example simulation and light-curve fit. The pages below
describe how to set up simulations for your own survey.
